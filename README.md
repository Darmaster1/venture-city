# Venture City
Live one-day startup-economy simulation. Source of truth for money, resources, contracts, scoring.
- Stack: Next.js 14 App Router, Prisma + Vercel Postgres/Neon, JWT (jose), Tailwind with custom tokens, polling (no websockets).
- Journal is the only record. Balances are derived. See PART 1/4 of the build prompt.
- Run: `npm run dev`, open `/board`. GM console at `/gm`. Desks at `/bank /investor /customer /talent /supplier /logistics /government /media`.
